Scout 體能儲備與同行匹配說明書

這個功能把你的近期活動紀錄整理成「現在適不適合這趟行程」的參考，也能協助比較同行者的行走節奏是否接近。它是出發前討論與行程後回顧的輔助工具，不會替你做安全決定。

體能趨勢 同行匹配 每日預覽 出發前 package

這是什麼

Scout 會讀取你已整理過的活動紀錄，例如手錶、運動裝置、GPX 路線或 Scout 完成紀錄，整理出近期體能狀態、活動負荷與同行節奏參考。

先講清楚：這不是醫療診斷，不是保證安全，也不會自動決定你能不能出發。它只是把資料整理成比較容易理解的提醒，最後仍由你、領隊或操作員判斷。

可以幫你什麼

出發前 知道自己最近是否偏累

用近期活動紀錄看出目前體能大致落在哪個狀態，避免只靠感覺判斷。

同行者 比較行走節奏是否接近

幫助隊伍討論速度、休息頻率、分工與撤退策略。

行程後 回顧預估和實際差異

看出哪一段開始疲勞、休息是否足夠，下次規劃更準確。

使用前準備

一般使用者不需要理解資料格式，只要準備「已整理過的活動摘要」。這些摘要可以由 Scout、操作員或匯入工具從 Apple Watch、Garmin、GPX、FIT、TCX 等資料整理出來。

你需要提供 近期幾筆活動紀錄摘要。越多筆越能看出個人趨勢。
Scout 會產生 體能儲備狀態、每日預覽、同行匹配資料，以及出發前可使用的本地 package。
Scout 不需要 完整原始健康資料、完整軌跡、住家位置、精確時間戳或帳號密碼。

畫面操作

打開 Scout admin 的 pretrip 畫面，進入 Wearables 分頁。若你不是操作員，只需要知道每個按鈕大概做什麼；實際檔案位置可以由操作員協助填入。

  1. 在 Wearable activity summary path 填入活動摘要檔案位置。
  2. 按 Validate summary，確認這份活動摘要可以被 Scout 使用。
  3. 按 Import summary，把這筆活動加入 Scout 的本地紀錄。
  4. 按 Load inventory，確認已匯入的活動數量與來源。
  5. 選擇 Reference date，通常用今天或出發前的檢查日期。
  6. 按 Refresh reserve，更新體能儲備狀態。
  7. 按 Daily preview，查看像手機首頁一樣的摘要畫面。
  8. 若正在做出發前規劃，按 Apply to ETA，把體能狀態放進這趟行程的 review。
  9. 若有同行者資料，按 Refresh match，比較同行節奏是否接近。
  10. 行程後可以按 Energy feedback，回顧出發前預估與實際行程表現。

怎麼看結果

最重要的是兩個結果：體能儲備狀態與同行匹配結果。

體能儲備狀態

Normal 接近你近期平常狀態。仍然需要依天氣、路況與隊伍狀況判斷。
Watch 比平常低一些。建議保守看待速度、休息與負重。
Rest Suggested Scout 建議多休息或降低行程強度。出發前應認真討論調整。
Stop And Check 需要停下來確認身體狀態。這是提醒，不是自動安全判定。

同行匹配結果

匹配分數不是誰比較強，而是「節奏是否接近」。高分代表行走、爬升、下降與休息習慣比較接近；低分代表隊伍更需要事先討論速度、等候點、分隊方式或撤退條件。

同行與出發前交接

Scout 可以把每日預覽與同行匹配結果整理成一份本地 package，未來可交給手機或 Scout device 使用。這份 package 的目的是讓出發前 review 更完整，不是把資料上傳到雲端。

Daily Preview 今天狀態摘要

顯示目前體能儲備、近期負荷與下一步建議。

Companion Review 同行節奏參考

協助領隊或隊員事先看出可能的速度差距。

Handoff Package 出發前資料包

把這些摘要整理起來，供後續 Scout 或手機端使用。

隱私與安全邊界

請把它當成輔助判斷，不要當成安全保證。 真正是否出發、是否撤退、是否加休息點，仍由使用者、領隊或現場操作員決定。
隱私 不需要原始健康資料

Scout 只使用整理後的摘要，不應分享完整健康資料、完整軌跡或精確時間。

安全 不會自動改變安全狀態

這個功能不會自動發警報、不會呼叫救援流程，也不會替你批准出發。

解讀 不是醫療診斷

它看的是趨勢和負荷，不是疾病、健康風險或醫療建議。

給協助者：需要時才用 CLI

一般使用者不需要使用命令列。若 UI 還沒有完全串好，或操作員要重跑資料，可以使用下面三類命令。這一段是給協助者，不是日常使用者必讀內容。

展開 CLI 範例

建立體能儲備

cd /Users/alexwang0315/scout-fusion
PYTHONPATH=. venv/bin/python -m scout_energy_reserve build \
  --activity tests/fixtures/wearables/apple_health_clean_activity.json \
  --activity tests/fixtures/wearables/garmin_body_battery_provider_values.json \
  --activity tests/fixtures/wearables/apple_health_missing_hr_interval.json \
  --output-dir /tmp/scout-wearable-demo/outputs \
  --reference-date 2026-05-27 \
  --root /Users/alexwang0315/scout-fusion

比對同行者

PYTHONPATH=. venv/bin/python -m scout_companion_match score \
  --query-capsule /tmp/scout-wearable-demo/outputs/scout_companion_capability_capsule.json \
  --candidate-capsule /tmp/scout-wearable-demo/outputs/scout_companion_capability_capsule.json \
  --candidate-profile-ref candidate.local.demo \
  --output /tmp/scout-wearable-demo/outputs/companion_match_review.json

建立出發前交接 package

PYTHONPATH=. venv/bin/python -m scout_mobile_handoff build \
  --daily-home-preview /tmp/scout-wearable-demo/admin/wearables/outputs/daily_home_preview.json \
  --companion-match-review /tmp/scout-wearable-demo/outputs/companion_match_review.json \
  --output /tmp/scout-wearable-demo/outputs/mobile_energy_companion_handoff.json

最短操作路徑

一般使用者：匯入活動摘要 -> 更新體能儲備 -> 看每日預覽。

出發前：更新體能儲備 -> 套用到行程評估 -> 檢查同行匹配 -> 人工決定。

行程後：產生 energy feedback -> 回顧哪裡和預估不同。
