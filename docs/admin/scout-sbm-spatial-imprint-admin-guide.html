Scout SBM / Spatial Imprint Admin Guide

SBM means Spatial Based Marking. Scout's implemented name is Spatial Imprint. It plants route-aware, sensor-aware cues that can trigger for registered trip clients before a hazard, confusing turn, rest point, or risk zone.

location + route progress altitude / heading TTL / tombstone advisory cue only

What SBM Does

SBM / Spatial Imprint lets Scout plant an instruction, warning, note, or coordination cue into the trip's spatial context. It can trigger from route distance, GPS radius, altitude, heading, segment/CP, risk zone, risk score, and client group.

Boundary: SBM is an awareness cue. It is not a CP, not SOS, not Phase 1 safety state, and not runtime safety truth.
HazardCollapse wall warning

Trigger a voice cue before the team reaches exposed terrain.

NavigationConfusing turn

Warn stretched-out members before a non-obvious route change.

CoordinationTemporary rest point

Leader plants a short-lived cue during the mission.

UI Operation

/admin/pretrip

Use this to review pretrip-generated spatial imprint candidates. Accepted candidates can be exported to spatial_imprint_set.json and spatial_imprint_manifest.json. Disable uncertain cues rather than deleting evidence.

/admin/debug

Use this to observe store updates and trigger dry-run projections: spatial_imprint_store_updated, spatial_imprint_trigger_event, matched predicates, latest imprint id, and boundary flags.

Plant A Runtime Imprint

Create a request file containing store_path, trip_id, actor_ref, and an imprint object. Prefer TTL for temporary field instructions.

{
  "store_path": "/data/scout/runtime/runtime_spatial_imprints.json",
  "trip_id": "chilai_nanhua_day1",
  "actor_ref": "leader.alex",
  "reason": "Leader moved rest point to the next open area.",
  "imprint": {
    "imprint_id": "spatial_imprint.runtime.rest_point.001",
    "label": "臨時休息點",
    "kind": "team_coordination",
    "severity": "info",
    "planting_source": "operator_runtime",
    "anchor": {"anchor_type": "route_progress", "distance_m": 18420.0, "trigger_before_m": 100.0},
    "payload": {"payload_type": "voice_cue", "text_zh": "前方約一百公尺為臨時休息點，請隊伍在開闊處集合。"},
    "lifecycle": {"state": "active", "scope": "ttl_scoped", "ttl_seconds": 3600}
  }
}
PYTHONPATH=. venv/bin/python -m scout_cli imprint plant \
  --input /tmp/plant-rest-imprint.json \
  --dry-run \
  --json

PYTHONPATH=. venv/bin/python -m scout_cli imprint plant \
  --input /tmp/plant-rest-imprint.json \
  --authorized-by leader.alex \
  --json

Output includes scout_spatial_imprint_plant_tool_output, updated store, audit log, and boundary metadata.

Expire / Delete

Use expire when a cue was correct but no longer relevant. Use delete/tombstone when the cue was wrong, duplicated, or superseded.

Expire

{
  "store_path": "/data/scout/runtime/runtime_spatial_imprints.json",
  "imprint_id": "spatial_imprint.runtime.rest_point.001",
  "actor_ref": "leader.alex",
  "expired_at": "2026-05-28T11:10:00+08:00",
  "reason": "Team already passed the temporary rest point."
}
PYTHONPATH=. venv/bin/python -m scout_cli imprint expire \
  --input /tmp/expire-imprint.json \
  --authorized-by leader.alex \
  --json

Delete tombstone

{
  "store_path": "/data/scout/runtime/runtime_spatial_imprints.json",
  "imprint_id": "spatial_imprint.runtime.rest_point.001",
  "actor_ref": "leader.alex",
  "deleted_at": "2026-05-28T11:15:00+08:00",
  "reason": "Incorrect cue location; replaced by a new imprint."
}
PYTHONPATH=. venv/bin/python -m scout_cli imprint delete \
  --input /tmp/delete-imprint.json \
  --authorized-by leader.alex \
  --json

Climbing And Wilderness Effects

ScenarioEffect
Collapse wall or exposed terrainMembers receive warning before reaching the hazard
Confusing turnStretched-out teams can regroup before the turn
Temporary rest pointLate members receive updated rest instruction without radio relay
High-risk segmentScout reminds the group to shorten spacing or slow down
Altitude/heading disambiguationReduces GPS-only false positives near switchbacks or cliffs

Boundary Checklist

  • Advisory cue only.
  • No Phase 1 safety mutation.
  • No live /safety/* mutation call.
  • No model-output-as-trigger-truth.
  • Plant, expire, and delete all retain audit history.
