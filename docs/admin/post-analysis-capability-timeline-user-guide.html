Scout Post-Analysis

行後能力時間軸：看懂自己這次怎麼走完路線

這個功能會把完成後的路線記錄整理成容易閱讀的時間軸，讓你知道每一段花了多少移動時間、休息多久，以及哪些資料可以安全地分享給同行者參考。

回顧節奏 看出是走得慢、休息多，還是哪一段特別花時間。
保留隱私 預設不分享原始 GPX、精確時間、事故細節。
只做參考 這不是安全保證，也不會影響行進中的安全判斷。

它會幫你回答什麼問題

完成路線後，Scout 會把你實際走過的記錄切成幾個路段，並把總時間、移動時間、休息時間分開。這樣你不用只看一個總花費時間，也能知道自己的實際行進節奏。

移動時間 扣掉明顯休息後，真正用在移動上的時間。
總時間 從一個檢查點到下一個檢查點的完整花費時間。
休息時間 系統偵測到你停留在同一小範圍內的時間。

先記住：這不是安全判斷

行後能力時間軸只是在安全回來後整理已完成的紀錄。它可以當作回顧和未來規劃參考，但不會決定你現在是否安全，也不會自動批准下一次出發。

它會做

  • 讀取你完成後的路線紀錄。
  • 把路線拆成幾段來看。
  • 顯示移動、休息與總時間。
  • 產生可追溯的行後分析檔案。

它不會做

  • 不會改變行進中的安全狀態。
  • 不會重寫已完成的事故或任務紀錄。
  • 不會預設公開原始 GPX 或精確時間。
  • 不會把一次紀錄當成永久能力標籤。

一般使用流程

你可以把它想成「完成路線 → 產生分析 → 在後台查看 → 決定是否分享摘要」。

1 完成路線

Scout 或使用者匯入完成後的 GPX 紀錄。

2 產生分析

系統切分路段，計算移動、休息與總時間。

3 在 /admin 查看

用時間軸看每一段表現，點選路段查看細節。

4 選擇是否分享

只分享粗略摘要，並先看清楚會包含與排除哪些資訊。

在畫面上怎麼看

在 /admin 看行後分析

  1. 打開 Scout admin 頁面。
  2. 在左側證據清單選擇 Capability Timeline。
  3. 右側會出現路線時間軸。
  4. 點選任一路段，可以看到該段的移動時間、總時間、休息時間、距離與可信度。
  5. 往下看 Share Preview，確認分享摘要會包含什麼、排除什麼。

在 /admin/pretrip 看未來規劃參考

如果後續要規劃類似路線，pretrip 頁面可以讀入這份行後能力時間軸，作為人工檢查時的參考。它不會自動調整 ETA，也不會自動改任務圖。

進階：用命令列產生分析檔

一般使用者通常只需要在畫面上查看。如果你是操作員，或要先用本機檔案產生分析，可以用下面的命令。你只要準備完成後的 GPX、路線檢查點資料、輸出資料夾。

PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=. ./venv/bin/python -m post_analysis_capability \ --case-id my_completed_route \ --completed-track-gpx /path/to/completed_track.gpx \ --checkpoint-definitions /path/to/checkpoints.json \ --output-dir /path/to/output_folder
你要提供 代表什麼
completed_track.gpx 你完成路線後的 GPS 軌跡。
checkpoints.json 路線上的檢查點與分段資料。
output_folder 分析結果要放在哪個資料夾。
如果要分享摘要 系統會先產生分享預覽。真正匯出分享檔時，必須明確確認；不會偷偷公開原始路線。

產出的檔案會做什麼

輸出資料夾會出現幾個檔案。一般使用者不需要手動打開全部，知道用途即可。

capability_timeline.json 完整時間軸資料，給後台畫面顯示每個路段。
capability_capsule.json 粗略能力摘要，可作為分享或同行參考的基礎。
capability_share_preview.json 分享前預覽，列出會包含與排除的資訊。
capability_segments.csv 每一段的表格摘要，方便人工檢查或匯入試算表。
capability_route_time_comparison.json 如果有參考步程時間，會顯示資訊性比較。

分享前會保護什麼

分享用的能力摘要只保留粗略表現，不預設公開敏感紀錄。這讓你可以和可能同行的人討論節奏，而不必交出完整路線軌跡。

  • 不包含原始 GPX。
  • 不包含精確時間戳。
  • 不包含精確座標。
  • 不包含事故細節。
  • 不包含私人備註或住家/工作路徑。

常見問題

它可以直接告訴我下次能不能走某條路嗎？

不可以。它只能當作回顧與規劃參考。下次路線仍要看天氣、隊伍、裝備、體力、撤退點與實際地形。

慢慢走會被當成休息嗎？

不一定。系統不只看速度，也看你是否停留在同一小範圍內。如果你慢慢移動但持續離開原地，通常仍會被視為移動。

為什麼有些路段可信度比較低？

可能是 GPS 記錄不完整、時間資料缺漏、路線點太少，或檢查點附近有多個可能匹配位置。這些情況會在畫面上顯示限制說明。

這會影響 Scout 行進中的安全判斷嗎？

不會。它只讀取完成後資料，不會改變行進中的安全狀態。
