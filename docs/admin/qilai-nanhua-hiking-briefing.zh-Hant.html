Trip length decision

預計幾天可以完成？

建議
2D1N

奇萊南華最常見也最穩妥的安排是 2 天 1 夜：第一天到天池山莊，第二天輕裝登奇萊南峰、南華山，再回程。若活動目標包含歷史、生態、地形觀察，3 天 2 夜會更適合。

2 天 1 夜

標準活動方案

可完成兩座百岳與主要景點，但第二天較長，需清晨出發並控管回程時間。

適合：一般有過夜裝備與中級山經驗者。
3 天 2 夜

觀察型方案

把光被八表、日出、雲海、歷史遺構與植被觀察拆開，不必在第二天壓縮所有內容。

適合：教學、親友團、攝影或首次高山過夜。
1 日

只給熟手

可行但路程長、海拔高，且雲天宮線前段爬升與雨後落石風險會放大失誤成本。

適合：熟悉路線、體能強、天候穩定且有撤退紀律者。
活動簡報建議採 3 天 2 夜設計，實際執行可依隊伍體能壓縮為 2 天 1 夜。

Route structure

兩天一夜標準路線

路線主軸是能高越嶺道西段加上奇萊南峰、南華山支線。第一天重點是進山、適應海拔、留足餘裕；第二天重點是清晨輕裝攻頂與午後安全下撤。

D1：進山到天池山莊

0K雲天宮登山口暨服務站，完成報到或登山登記。
約 4.3K雲海保線所：休息、補水、看雲霧與舊保線建築。
約 7.8K松原駐在所、木炭窯遺址：日治警備道與山林生活痕跡。
13.1K天池山莊：住宿、晚餐、確認隔日天氣與撤退時間。

D2：雙峰與回程

清晨天池山莊到天池岔路，視天候先走奇萊南峰或南華山。
3358 m奇萊南峰：高山草坡、中央山脈展望、黃金大草原日出。
3184 m南華山：又稱能高北峰，稜線狹長，視野開闊。
可加走光被八表紀念碑，再回天池山莊收裝下山。

Context layers

把路線拆成六個脈絡層

這份活動的主題不是「打卡兩座百岳」，而是讓隊員知道每一段路為什麼存在、怎麼變成今天的樣子，以及在哪些地方該慢下來。

歷史層

社路、警備道、保線路

能高越嶺道先是賽德克族遷徙、狩獵與交易路徑；日治時期擴建為警備道路；戰後又成為台電東西輸電與保線路。

文化層

地名與山名

南華山又稱能高北峰，舊稱「楠花山」，與石楠花、能高山群地名連在一起；路線也保留原住民族社路與日治地名層疊。

自然層

林相、鳥類、山椒魚

從中海拔林相逐步進入高山草坡與箭竹，沿線常見山鳥，天池山莊周邊溪谷與碎石環境也有山椒魚棲地紀錄。

地形層

鞍部、稜線、崩壁

雲天宮線是崩塌後的重要替代入口；光被八表所在能高鞍部是中央山脈主脊與縣界地標，稜線風、午後霧、崩塌地都會影響節奏。

季節層

梅雨、低溫、雲海

夏秋可看瀑布與草坡，冬季有低溫與結冰風險；梅雨或颱風後土石鬆動，路況判斷優先於完成山頭。

觀察層

停 3 分鐘的地方

雲海保線所、松原遺址、天池山莊晨昏、奇萊南峰草坡、南華山稜線與光被八表，都值得安排短暫解說與隊伍重整。

P2 Scout-owned context

把完成旅程變成下一次的路線脈絡

P0/P1 回答「公開世界怎麼描述奇萊南華」，P2 則回答「Scout 實際走過後，這條路對這個隊伍代表什麼」。本次公開簡報不假造 P2 證據；以下是匯入 completed trip 後應累積的資料槽與使用方式。

實走軌跡與偏航

使用者 GPX、分段耗時、偏航紀錄與折返點，可回饋雲海保線所、松原駐在所、天池山莊到雙峰稜線的 pace fit 與 route note。

停留、照片、語音註記

停留點、拍照點、語音註記與「值得停 3 分鐘」回報，可把公開景點轉成更貼近隊伍記憶的 observation point。

IMU / PDR / 氣壓高度

步態異常、氣壓高度變化、坡段通過節奏與定位品質，能補足 GPX 在林相、雲霧、山屋周邊或稜線風口的盲點。

隊伍狀態

前鋒/後衛距離、隊伍拉長、長時間低速、休息營地與補水行為，可標記下一輪 pretrip 的 regroup point 與 body battery 參考。

Scout action log

打卡、提醒、模型提示詞、skill 使用、通訊嘗試與最小事件包，屬於 Scout 黑盒子紀錄；可做事後分析，不直接變成安全真相。

人工 review 後才進包

P2 先作為候選 evidence。只有經使用者或 AI 輔助 review 的片段，才可進入下一次 reviewed trip package 或 route context briefing。

3-minute observation stops

哪些地方值得停 3 分鐘？

3

雲海保線所

看雲霧是否正在越嶺，順便檢查隊員水量、腳程、衣物與呼吸。

3

松原駐在所、木炭窯

把「古道」從抽象名詞變成可觀察的平臺、駁坎與燃料使用痕跡。

3

天池山莊外

看風向、雲底高度、午後霧線與隔天凌晨出發條件，不只把山屋當住宿。

3

奇萊南峰草坡

觀察光線如何掃過草坡、箭竹與稜線，也注意風寒與隊員保暖。

3

南華山稜線

辨識鞍部、谷線、風口與能高主峰方向，讓地形不只是背景。

3

光被八表

用紀念碑講東西輸電、縣界、分水嶺與山區工程，不只拍合照。

不建議停留：崩塌地、落石區、狹窄邊坡、隊伍後方已拉長的路段。這些地方只做安全通過，不做解說。

Operational guardrails

活動風險與行政事項

公告優先

出發前一天重查天池山莊最新消息、台灣山林悠遊網、道路與天氣。若有豪雨、颱風、地震後路況不明，改期比硬走更合理。

申請分流

天池山莊住宿需線上申請；攀登奇萊南峰需另向國家公園申請入園，南華山與天池山莊周邊本身不屬太魯閣入園範圍。

服務站報到

能高越嶺西段 0K 為雲天宮登山口暨服務站；住宿或單日往返都要依規定登記。

高山症

天池山莊約 2860 m，奇萊南峰 3358 m；頭痛、噁心、步態異常不該被解讀成體能差。

午後與夜間

第二天很長，若天氣差或隊伍速度不足，應砍掉光被八表或單峰，而不是摸黑硬下。

無痕山林

指定宿營、垃圾與廚餘帶下山、禁喧鬧與播放音樂，不干擾野生動物與山屋秩序。

Recommended itinerary

建議行程版本

版本 安排 優點 取捨
標準 2 天 1 夜 D1 雲天宮線進天池山莊；D2 奇萊南峰、南華山，視時間加光被八表後下山。 住宿一次即可完成雙峰，最符合多數隊伍假期。 D2 長，觀察時間有限；需嚴格設定折返時間。
觀察 3 天 2 夜 D1 進天池；D2 雙峰與光被八表；D3 雲海、遺構與植物觀察後下山。 最符合這份簡報的脈絡層設計，隊伍壓力小。 需連續住宿名額與更多食物裝備管理。
壓縮 1 日 凌晨起登，雙峰折返，通常不安排深入解說。 不用抽山屋。 不建議作為一般活動；天候、體能、摸黑與高山症風險高。
