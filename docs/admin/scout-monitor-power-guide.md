# Scout monitor：電池與供電判讀

2026-09-14 · 唯讀監控 · 繁體中文

## 從 Dashboard 開啟

在 System 選擇 scout monitor，或開啟：

http://127.0.0.1:9099/admin/dashboard#scout-monitor

Mac 的全頁入口是 http://127.0.0.1:9099/admin/dashboard/scout-monitor。
9099 後端在 Mac 原生執行，新版代理每次透過既有 scout SSH 設定直接讀取
Scout 的固定 127.0.0.1:9151 API，不需要 Mac 的 9151 監聽埠或常駐轉接。
瀏覽器只使用 Dashboard 同源 GET。Scout 上的獨立總覽仍位於其自身
http://127.0.0.1:9151/monitor；不是 Mac 的 localhost。
後端程式更新後需重啟 9099 才會載入；只重新載入網頁不會更新舊後端。
更新完成後請重新整理 Dashboard 一次。內嵌監控文件使用版本識別與禁止快取
標頭，避免繼續顯示舊版；不改變同源 API 與唯讀權限。

## 電池未知，不等於主機供電未知

- 「UPS 通訊失敗（I²C），電池讀值未知」：UPS 電池遙測無法讀取。
  電量、充放電、電池功率及電壓維持未知；不以最後成功值或零補上。
- 「5V 5.16 V」這類數字：主機 PMIC 仍有有效供電電壓觀測。
  範例數字不是目前讀值；請以畫面的採樣時間及實際數字為準。
- 5V 可讀不代表 UPS 通訊已恢復，也不能據此認定 UPS 本體、接線、
  電池容量或備援供電功能正常。整體仍維持後端告警。
- 「主機供電資料部分不可讀」：電壓或欠壓／降頻旗標中有讀取失敗。
  有效項目仍保留，缺失項目不補零；有效 UPS 電池資料不會被連帶清除。

## 刷新、過期與告警

「重新讀取」只讀取結果，不會重新掃描或控制硬體。背景每 60 秒更新，
離開監控頁會取消輪詢及未完成請求。

Mac 睡眠、網路或 SSH 暫時失聯後，下一輪讀取會建立新 SSH 連線，不依賴
先前的暫時轉接程序。SSH 主機金鑰與登入權限仍必須有效；不會略過驗證。
「SSH 已連通，但 Scout 的 9151 API 無法連線」表示要確認 Scout API 服務，
不是再開 Mac 9151。逾時請求會清理它自己的 SSH 子程序；不停止其他 SSH。

查看最後採樣時間（台北）與資料年齡。超過 150 秒的 API 回應會標示
「資料已過期」；斷線時顯示最後收到的紀錄，不能視為目前狀態。
電源來源本身的有效期限仍使用後端門檻，不因本次分離而放寬。

目前告警與門檻由後端提供。電池資料可讀時保留低電量告警；主機旗標
可讀時保留欠壓／降頻告警。歷史旗標與當下旗標不同，不可混用。

## 設備清單與安全界線

設備分類、屬性及 GPIO 線路可展開；刷新後保留展開狀態。
I²C UPS 的存在資訊只來自有效 UPS 觀測，沒有主動位址掃描。
風扇 0 RPM 不單獨代表故障；GPIO 未採樣電位顯示「未採樣」。

本次是資料處理與顯示修正，不是 UPS 通訊修復。沒有新增硬體控制、
配對、探索、GPIO 讀寫、序列埠操作或安全決策權限。
