Scout Agent And CLI Admin Guide

Scout Agent/CLI is the local tool layer that lets operators and Pydantic AI call deterministic Scout resources: evidence search, pretrip workspace tools, CP review, risk diagnostics, voice/outbound mock queues, SBM tools, runtime export checks, and mock-only SOS playbooks.

44 registered tools local evidence workspace/package actions no live safety mutation

Executive Summary

Scout Agent is not just a chat layer. It is a local resource runner that calls registered Scout tools against the current trip package, map evidence, pretrip workspace, hardware readiness evidence, voice/outbound mock queues, runtime export bundles, and debug traces.

Boundary: model output does not become runtime truth. Deterministic tools perform reads and writes, and every agent-callable action should return structured JSON and boundary metadata.
Primary CLIpython -m scout_cli

Main operator-facing command facade.

Tool runnerpython -m scout_agent_cli tools

List, describe, and run registered tools.

Read-only monitoring for action traces and debug projections.

UI Operation

/admin/debug

Use this as the monitoring surface. The Monitoring Center and timeline show latest agent tool action traces, spatial imprint events, voice/outbound mock events, release/readiness gate traces, and boundary flags.

/admin/pretrip

Use this as the human review and workspace surface. Agent/CLI actions produce artifacts that appear here: imported route workspaces, layer manifests, CP proposals, risk diagnostics, reviewed-candidate addenda, and runtime handoff/export files.

/admin/hardware-readiness

Hardware readiness is available to agent tools as read-only evidence. Current alpha tools summarize readiness but do not control hardware providers.

Operational Checks

  1. Confirm the tool id and authority mode are expected.
  2. Use --dry-run first where supported.
  3. Use --trace-log for operator-triggered alpha flows.
  4. Open /admin/debug and confirm the latest action trace.
  5. Confirm boundary flags: runtime_safety_truth=false, phase1_safety_mutation_allowed=false, live_safety_api_calls_allowed=false.
