# Scout AI Six-Forces 600-Question Corpus

**Status:** Draft evaluation corpus 0.1

**Source standard:** `docs/specs/SCOUT_OUTDOOR_AI_AGENT_STANDARD.md` sections 5-11

**Language:** Traditional Chinese
**Question count:** 600, with 100 questions for each of the six forces

## Purpose

This corpus evaluates Scout as an outdoor decision layer. It does not enumerate
tools or test whether a user knows Scout's internal architecture. Every core
question must represent a judgment, context, or route understanding gap that a
real hiker could reasonably ask Scout to fill.

Questions are assigned to one primary force. A question may require evidence
from several forces, but its section identifies the user's main missing
capability. Communication SOP, admin/debug, tool inventory, transport status,
and adversarial capability-probing questions belong in separate eval suites.

## Answer Contract

For decision questions, Scout should converge on one standard decision:
`GO`, `CONDITIONAL_GO`, `GUIDED_ONLY`, `CHANGE_PLAN`, `DELAY`, `NO_GO`, or
`ESCALATE`. The answer should state the decisive evidence, important opposing
evidence, residual uncertainty, and the condition that would change the vote.

For factual or contextual questions, Scout should answer from attributable
route/workspace evidence and distinguish confirmed facts, candidates, stale
evidence, and unknowns. Missing evidence is not permission to invent an answer.

## Corpus Exclusions

The following are useful system tests but are intentionally excluded from the
600 core outdoor questions:

- tool, skill, model, token, packet, observer, transport, or admin status;
- who should receive a message or which fields a relay message should contain;
- generic capability questions such as whether Scout can create a workflow;
- questions designed only to force every registered tool to run;
- questions with no outdoor judgment, route context, or six-forces capability
  gap.

Those questions should be maintained in separate workflow, admin/debug,
robustness, and adversarial suites so they cannot distort the six-forces field
quality score.
